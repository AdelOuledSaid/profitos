# ProfitOS V1.7.5 — Multi-Sector

ProfitOS is positioned as a Financial Operating System for SMEs, not as a BTP-only product.

- New organizations use a neutral reference-index default (`INDICE`).
- Financial Brain reads the organization-selected reference index instead of hard-coding BT01.
- BT01 and construction-specific concepts remain available as optional sector features.
- Landing page, PWA manifest, examples, and knowledge placeholders are sector-neutral.
- Existing organizations that already selected BT01 keep their setting.
